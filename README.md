# Python Minigames
A **terminal-based application** that features a simple **Rock Paper Scissors** and a **Guess the Number** game. 

## Featured Games

### Rock Paper Scissors

- Computer randomly choose Rock, Paper, or Scissors.
- User chooses Rock, Paper, or Scissors.
- First to win 5 rounds wins.
- Ties can happen and does not impact the scores.
- Type 'S' to stop the game at anytime
- Can play again after game ends.

### Guess the Number

- Guess a number between 1 and 100 that is randomly generated.
- User gets 10 attempts to guess the correct number.
- The game tells user if the number guessed is too high or too low.
- Duplicate guesses will not count.
- Type 'S' to stop the game at anytime.
- Can play again after game ends.

## Features

- Interactive game menu
- Input validation
- Error handling
- Score tracking
- Replay options
- Randomization using Python's 'random' libray

## Requirements
- Python 3.x

## How to Run Program

- 1. Clone this repository.
- 2. Open project folder in a terminal.
- 3. Execute the script using Python:
     python main.py
